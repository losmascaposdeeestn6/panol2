# Sistema de Pañol - Control de Herramientas

Sistema web para el control de stock y órdenes de herramientas de un pañol técnico.

## Funcionalidades

- **Stock de Herramientas**: Vista completa del inventario con estadísticas y búsqueda.
- **Nueva Orden**: Registro de retiro de herramientas por alumno con profesor del aula y aula (opcional).
- **Nota Recordatoria**: Comprobante imprimible con firma del alumno y profesor.
- **Historial de Órdenes**: Registro completo con opción de marcar devolución y devolver stock.
- **Administrar Stock**: Agregar, modificar y eliminar herramientas del inventario.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- LocalStorage para persistencia de datos

## Uso

Abrir `index.html` en cualquier navegador web moderno.
